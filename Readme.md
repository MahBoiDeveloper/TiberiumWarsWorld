# Tiberium Wars World

... is a fan made map package for Command &amp; Conquer 3: Tiberium Wars with singleplayer/cooperative missions, art of defenses, and other PvPvE game modes maps. All maps in the map pack have been edited to be easy to translate and easy to find by name. No balance patches have been integrated into the maps.

List of included maps, campaigns, map packs with edit:
* [Art of Defense - Tiberium Grounds](https://www.moddb.com/groups/art-of-defense-fans/addons/art-of-defense-tiberium-grounds-cc-3-tw)

## Installation

Copy maps from `Source\` folder to your local `%APPDATA%\Command & Conquer 3 Tiberium Wars\Maps\` folder.
